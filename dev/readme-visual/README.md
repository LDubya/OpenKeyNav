# README visual source

`demo.html` is a compact capture fixture that loads the repository's real UMD build. `storyboard.html` arranges three browser captures from that fixture into the static image used near the top of the package README.

Capture the initialized fixture, its Click Mode labels, and the completed Juniper action at a 520 × 420 viewport. Save those files as `captures/step-1.jpg`, `captures/step-2.jpg`, and `captures/step-3.jpg`. Render the storyboard at 1500 × 610 and save it as `media/openkeynav-click-mode-steps.jpg`.
