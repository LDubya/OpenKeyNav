Structural navigation keys
  • Shift + O enables OpenKeyNav; R enters structural navigation.
  • Tab / Shift + Tab moves sequentially using native browser focus.
  • Shift + Up / Down moves to the parent / child context without moving focus.
  • Shift + Left / Right moves to the previous / next context at the same heading level—even across parent headings—and focuses its first stop. Unheaded contexts use structural siblings.
  • Inside an arrow-owning control, add Alt to a structural Shift + arrow command to override the widget.
  • F7 / F8 cycles explicit typed routes in the Typed workspace example.
  • Alt + R exits while preserving focus.
