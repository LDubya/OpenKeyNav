OpenKeyNav Production Demo PRODUCTION MODE

This page demonstrates OpenKeyNav in production mode (debug.keyboardAccessible = false). Press Shift+o to enable, then k for click mode or m for move mode.

Production mode differences:

  • No audit panel on enable
  • No red outlines on inaccessible elements
  • Click mode shows only accessible elements
  • No debug count in toolbar
